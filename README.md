# Doctor Stream

A Windows application for saving YouTube videos you own or have permission to download, as MP4 video or MP3 audio.

## Download

The 1.1.1 beta release is prepared as a draft. The public installer download is not available yet.

[Releases](https://github.com/Eng-Chiremba/Doctor-Stream-Releases/releases)

## Features

- Paste a video link to automatically find its title and available qualities.
- Choose MP4 video or MP3 audio and select the output quality.
- Choose your save folder; pause, resume, cancel, or retry a transfer.
- Find completed files from the download history.
- Install newer versions over the existing app, keeping your settings and history.

## Install or update

Download and run the Setup EXE. Close Doctor Stream before upgrading. The installer includes the required runtime and media tools. Internet is needed for video lookup and downloads.

Target platforms: Windows 10 22H2 / Windows 11, x64. Clean-machine compatibility has not yet been fully validated.

## Beta status

This is an **unsigned beta**. Windows may show an unknown-publisher warning or block it under stricter security settings. Only install software from a source you trust; do not disable Windows protection. A local Defender scan reported no threats, which does not guarantee acceptance on every computer.

Download only content you own or have explicit permission to save. Protected, restricted, authenticated and live sources are unsupported. Source availability and download speeds vary.

Trusted publisher signing, clean-machine validation and the exact bundled-tool corresponding-source/build redistribution review remain outstanding. The installer includes third-party license notices; this repository does not claim that review is complete.
